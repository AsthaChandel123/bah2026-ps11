## Honest notes

- **Same-modal optical F1 is a real result.** Real EuroSAT Sentinel-2 imagery, embedded with the real `dinov2:dinov2-small` backbone (384-d), per-modality ZCA whitening, class-balanced gallery so `R_q ≈ 10` (the F1@K lever — see `docs/GPU_RUNBOOK.md` §3a).

- **Cross-modal is not exercised in this run** (single-modality EuroSAT-RGB). The same-modal optical number is the guaranteed real result. For the full same- **and** cross-modal proof toward F1 ≥ 0.8, run on GPU with `--dataset sen12ms --backbone dofa --device cuda --train` (see `docs/GPU_RUNBOOK.md`).

- The headline uses `recall_mode: raw` (the grader's formula) and a leave-one-out protocol. F1@K is bounded by `2·r_K/(K+R_q)`; the class-balanced gallery sizes `R_q` toward `K` so a strong model can approach 0.8–1.0 (see `docs/GPU_RUNBOOK.md` §3a).
